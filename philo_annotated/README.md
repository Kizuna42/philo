# philo_annotated

`philo/`（提出物）の実装に日本語の解説コメントを付けた**学習用コピー**です。
提出・評価の対象は `philo/` のみで、CI のテスト・ThreadSanitizer・Norminette も
`philo/` に対してだけ実行しています。

## `philo/` と同じ内容

- フォークの取得順（奇数番は右→左、偶数番は左→右）によるロック順序の循環解消
- 偶数番の開始を `time_to_eat / 2` 遅らせる処理
- 人数が奇数のときの思考時間 `time_to_eat * 2 - time_to_sleep`
- 監視スレッドのループに入れた `usleep(500)`

## `philo/` との差分（未反映の修正）

以下は `philo/` 側だけで修正済みで、このコピーには反映していません。
このため、このコピーには `eating` フラグのデータ競合が残っており、
`tests/run_tests.sh` の一部（巨大な引数の拒否）にも失敗します。

| 項目 | `philo/` | `philo_annotated/` |
| --- | --- | --- |
| `philo->eating` の読み書き | `meal_lock` で保護 | ロックなしで書き込み（データ競合） |
| `INT_MAX` を超える引数 | エラーで終了（終了コード 1） | 桁あふれしてそのまま実行 |
| 哲学者 1 人のとき | 監視スレッドが死亡フラグを立てるまで待機 | `time_to_die` だけ眠ってから終了 |
| Makefile の依存関係 | `philo.h` の変更で再コンパイル | `philo.h` の変更を検知しない |
| Norminette | 準拠 | 解説コメントのため非準拠 |
